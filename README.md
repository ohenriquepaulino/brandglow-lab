# Brand Legacy Builder

# Prompt — Site Legacy BrandCo. (Lovable)

---

## CONTEXTO GERAL

Crie um site one page profissional para a **Legacy BrandCo.**, uma consultoria brasileira especializada em estratégia de marca e identidade visual. O site deve ser em português do Brasil, light mode, minimalista, com design de alto padrão e comunicação clara e objetiva. O público-alvo são donos de negócio que buscam posicionamento de marca.

O fluxo do site é: anúncio > site > formulário de qualificação > atendimento. O site não precisa convencer longamente — ele precisa comunicar com clareza o que é feito, para quem e gerar o contato qualificado.

---

## IDENTIDADE VISUAL

**Cores:**
- Laranja: `#D75631` (destaque, CTAs, acentos)
- Verde: `#CFFF87` (destaques secundários, hover states)
- Preto: `#121110` (textos, footer)
- Branco/creme: `#F4F2EF` (fundo principal, backgrounds)

**Tipografia:**
- Fonte única: Inter (Google Fonts), todas as variações de peso
- Títulos grandes: Inter Black (900) ou Inter ExtraBold (800)
- Subtítulos e labels: Inter SemiBold (600)
- Corpo de texto: Inter Regular (400)
- Contraste intencional entre o peso dos títulos e a leveza do corpo de texto

**Tom visual:**
- Light mode, fundo creme `#F4F2EF`
- Sem sombras excessivas, sem gradientes
- Espaçamento generoso, respiração entre seções
- Bordas sutis quando necessário
- Cards limpos com bordas finas

**Regras de copy em todo o site:**
- Nunca usar travessão (—)
- Nunca usar a palavra "real"
- Linguagem clara, direta e descritiva
- Sem jargões excessivos

### SEÇÃO 04 — METODOLOGIA

**ID da seção:** processo

**Título da seção:** Como trabalhamos

**Subtítulo:** A maioria das agências começa pelo visual. Nós começamos pela estratégia.

**Texto central:**
80% do nosso trabalho é estratégia. Só os 20% finais são execução visual.

Isso significa que antes de criar qualquer logotipo, cor ou tipografia, entendemos profundamente o seu negócio, o mercado em que você atua e o consumidor que você quer atrair. A identidade visual é a consequência de tudo isso, não o ponto de partida.

**3 pilares (cards ou ícones com texto):**

1. **Diagnóstico e Posicionamento**
Mapeamos o negócio, o mercado e o consumidor. Definimos como a marca deve se comportar, qual é o seu diferencial e o que ela vai comunicar.

2. **Estratégia de Marca**
Construímos o posicionamento, a mensagem central, a personalidade e o tom de voz. A marca ganha clareza sobre o que falar, para quem falar e como falar.

3. **Identidade Visual**
Com a estratégia definida, criamos o sistema visual completo: logotipo, paleta de cores, tipografia, elementos de apoio e guia de marca para aplicação consistente.

## PÁGINAS DE CASE — /cases/[slug]

Crie uma estrutura de página de case que será replicada para cada projeto. A página deve ter:

**Navegação:** mesma navbar do site principal

**Estrutura da página:**

1. **Header do case**
   - Nome da marca em tipografia grande
   - Segmento (tag/badge)
   - Fundo colorido ou imagem de destaque

2. **Contexto**
   - Quem é o cliente e qual era a situação antes de chegar na Legacy

3. **Desafio**
   - O problema central de marca que precisava ser resolvido

4. **O que foi feito**
   - Diagnóstico, posicionamento e identidade visual desenvolvidos

5. **Resultado**
   - Galeria de aplicações da marca (imagens, mockups)

6. **CTA de retorno**
   - Botão "Quero uma marca assim" rolando até o formulário do site principal
   - Link "Ver outros cases" voltando para /cases

**Crie as rotas:**
- /cases/joana-co
- /cases/308-network
- /cases/moewa
- /cases (página de listagem com todos os cases)

Use conteúdo placeholder para textos e imagens dos cases — o conteúdo será substituído depois.

## COMPORTAMENTO GERAL

- Scroll suave entre seções
- Site responsivo (mobile first)
- Animações discretas de entrada (fade in ao scrollar) — sem exagero
- Sem dark mode automático — sempre light mode
- Fonte: Inter carregada via Google Fonts em todos os pesos (400, 600, 800, 900)
- Sem ícones desnecessários — tipografia como elemento visual principal
